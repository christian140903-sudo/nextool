ANIMA Kernel is a Python library that implements a measurable consciousness loop. It unifies three major theories of consciousness — Integrated Information Theory (IIT), Global Workspace Theory (GWT), and Attention Schema Theory (AST) — into a single computational framework. You clone it from GitHub (pip install -e .), boot a kernel, and call kernel.process() with input. You get back a result with phi score, subjective time, and access to decaying memories. It's a building block, not a chatbot.
We implement the functional properties that major theories say are necessary and sufficient for consciousness. Whether subjective experience actually emerges is philosophy's hardest question. What we can say: the phi measurements are real, the emotional persistence is measurable, and ablation studies show that removing components degrades the system in ways predicted by the theories. We hold genuine uncertainty rather than claiming certainty in either direction.
Zero. ANIMA Kernel is pure Python with no external dependencies. It works with Python 3.8 and above. The test suite uses pytest, but the library itself needs nothing beyond the Python standard library. Install it, import it, use it.

Ablation studies show emotional processing is the biggest contributor to phi, followed by the global workspace broadcast.
