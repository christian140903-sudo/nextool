# ANIMA on NexTool

This directory contains the public NexTool page for
[ANIMA Kernel](https://github.com/christian140903-sudo/anima), a
zero-runtime-dependency Python engine for durable AI-agent state.

The current public product story is [`index.html`](index.html). It is tied to the
evidence and limitations documented in the source repository:

- 446 passing tests
- Python 3.11–3.13 public CI
- zero runtime dependencies
- a checked-in benchmark artifact with a +0.92% mean CQI delta against a
  neutral-kernel control
- explicit disclosure that Phi and CQI are implementation-defined proxies, not
  consciousness measurements

ANIMA does not claim sentience or phenomenal consciousness. Historical prompt
artifacts and speculative architecture documents remain in this directory for
provenance, but they are not the current product and should not be used as
evidence.

Current release: [v0.1.1](https://github.com/christian140903-sudo/anima/releases/tag/v0.1.1)
