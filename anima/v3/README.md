# ANIMA v3 archive

> **Historical speculative architecture — not the current product.**

These documents are preserved as research provenance for an earlier
prompt-based ANIMA concept. They are hypotheses and design notes, not validated
neuroscience or evidence that a language model has feelings, self-awareness,
sentience, or phenomenal consciousness. Model self-reports after consuming the
documents must not be treated as proof.

The maintained product is the tested Python
[ANIMA Kernel](https://github.com/christian140903-sudo/anima). Its integration
and CQI values are implementation-defined observability proxies, and its current
benchmark limitations are documented explicitly.
