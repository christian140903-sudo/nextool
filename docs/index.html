What the old ANIMA docs became

The former /docs/ page described a prompt document as if it could activate genuine affect or transform any model. That material is preserved as labeled historical provenance in the ANIMA repository, not presented as current product documentation. The maintained ANIMA Kernel is Python software; its state and behavior are testable, while sentience and phenomenal consciousness are not claimed.
