# nextool.app — personal site of Christian Bucher

Source of the static website served at <https://nextool.app>.

The site is being rebuilt in October 2026 as a small personal site. Only the
folder `site/` is deployed; everything else in this repository (build script,
linter, CI) stays out of the published output.

## Earlier content

Everything that was published here before the rebuild (browser tools, guides,
shop prototypes, a side project and older product pages) is preserved
unchanged on the branch
[`archiv/vor-relaunch-2026-10`](https://github.com/christian140903-sudo/nextool/tree/archiv/vor-relaunch-2026-10)
and in the git history. Old URLs redirect to `/archiv/` or to their successor
page (see `site/_redirects`).

## Layout

| Path | Purpose |
| --- | --- |
| `site/` | deployed output (generated by `npm run build`, committed) |
| `src/` | page sources, layout, facts, static assets |
| `scripts/` | build, linter, local preview server |
| `wrangler.toml` | Cloudflare Pages configuration (`pages_build_output_dir = "site"`) |

## Commands

Node 20 or later, no dependencies.

```sh
npm run build   # regenerate site/ from src/
npm test        # build check + site linter + linter self-test
npm run serve   # local preview with _redirects and _headers applied
```

## Photo

Pages place the portrait with `{{photo:large}}`, `{{photo:medium}}` or
`{{photo:small}}`. As long as `src/static/assets/foto.jpg` does not exist, the
build renders initials instead of an `<img>`, so no page points to a missing
file. To add the photo: put `foto.jpg` (required fallback) and optionally
`foto.webp` into `src/static/assets/`, each at most 150 KB and without
metadata (for example `exiftool -all= foto.jpg`), then run `npm run build`.
The build stops if a file is too large or still carries EXIF, XMP or IPTC
data, because those can reveal where and with which device a photo was taken.
