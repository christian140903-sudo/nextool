The Loop

v1 remembers. v2 is trustworthy. v3 thinks.

Every session, Soul computes deterministically what needs judgment: contradictions, near-duplicates, low-confidence inferences, expiring candidates, due predictions. The model answers through soul_resolve; the answer is validated and applied under guards enforced in code, not prompt.

A real assignment from a real run

+
{ "kind": "dispute", "instruction": "These memories are flagged as
contradicting. Judge: real contradiction, or
compatible statements? ...", "memories": [ { "content": "User prefers tabs for indentation" }, { "content": "User prefers spaces for indentation" } ], "respond_with": { "verdict": "..." } }

The model judges. If it tries to overrule a user statement:

{ "applied": false, "outcome": "needs_user", "detail": "The losing side is a user statement.
A model verdict never overrules the user." }

The loop is self-igniting. Compiling a context capsule is the moment assignments are computed. A capable model gets consolidation work without asking for it. Your memory carries that quality forward to every model that comes after.

Mechanism

Six layers. Fully integrated.

Event ledger with provenance on every fact. Conflict detection that catches contradictions the word-overlap heuristic misses. Consolidated memories that reshape ranking pressure without ever deleting. Calibration feedback from resolved predictions. Deliberation scaffolds enriched with the user's own validated procedures.

01

Denkpartner Protocol

Structured assignments (disputes, near-dupes, low-confidence inferences). Model resolves under guards. History kept, reversible. Strongest effect: supersession, never deletion.

02

Model-aware Capsules

Deep models (Opus, Fable, GPT-5) get briefing + up to two think-assignments. Fast models (Haiku, mini) get none. Same soul, tailored collaboration per model class.

03

Prediction Calibration

Register testable claims with probabilities. Due predictions resolve and return to the workbench. Soul computes actual calibration—Brier score, hit rate per confidence band. No base model knows this.

04

Deliberation Scaffolds

For decisions, diagnoses, estimates: decompose → counter-hypothesis → evidence → decide with confidence. Enriched with user's own validated procedures and the calibration record.

05

Semantic Retrieval

Opt-in local embedding (multilingual-e5-small). Hybrid search: FTS5 keywords + embedding neighbors, fused by documented formula. Every result: full score breakdown.

06

Consolidation Memory

Memories never recalled slowly lose importance. Memories that keep proving useful gain a little. Ported from anima-kernel research: deterministic, no deletion by decay.

What It Does NOT Claim

The honest line.

An MCP server cannot raise a model's raw reasoning power. Nothing turns a small model into a frontier one. Soul does something narrower and real: persistent memory with provenance, accumulated self-knowledge (calibration), structured deliberation, and a consolidation loop that compounds across sessions. Those are the axes on which models feel "a generation better"—continuity, reliability, self-awareness of limits.

Data & Policy

Everything local. Policy in code.

SQLite + WAL + Append-Only Ledger

+

Everything lives in ~/.soul/memories.db (SQLite, WAL). Policy lives in ~/.soul/constitution.json and is enforced in code:

  • Secrets are never stored—only a redacted rejection event remains
  • Injection-looking content is quarantined and never recalled
  • Sensitive categories wait for explicit confirmation
  • Private-sensitivity memories never enter a compiled context
  • Every mutation is an append-only ledger event
  • soul_timeline can answer: "what did you believe about X three weeks ago?"
