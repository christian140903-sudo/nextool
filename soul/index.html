The Core

What Soul 4.0.1 is right now.

A completely local-first memory and runtime environment for MCP clients like Claude Code, Cursor, and Windsurf. It gives your models a persistent brain with strict provenance.

01

Persistent Memory & Provenance

Every fact is stored locally with cryptographic-like provenance. Conflict handling resolves contradictions dynamically, ensuring the model's context is trustworthy and up-to-date.

02

Durable Runs & Receipts

Execution is tracked via durable runs. Every action generates an auditable receipt, providing complete transparency into what the model did and why.

03

Declarative Skills

Equip your agents with declarative skills that guide deliberation and execution. The system learns and compounds efficiency over time.

04

23 MCP Tools

A massive, production-ready suite of 23 MCP tools and 9 resources, operating entirely in SQLite. Zero cloud dependencies, zero telemetry.

Data & Policy

Everything local. Policy in code.

SQLite + WAL + Append-Only Ledger

+

Everything lives in ~/.soul/memories.db (SQLite, WAL). Policy lives in ~/.soul/constitution.json and is enforced in code:

  • Secrets are never stored—only a redacted rejection event remains
  • Injection-looking content is quarantined and never recalled
  • Sensitive categories wait for explicit confirmation
  • Every mutation is an append-only ledger event

Built with high engineering standards and explicit honesty boundaries.

CLI

Bootstrap & operate.

npx soul-mcp init # create ~/.soul (or migrate v1/v2/v3/v4) npx soul-mcp status # memories, ledger, integrity, semantic layer npx soul-mcp semantic on # enable local semantic retrieval (opt-in) npx soul-mcp doctor # health checks
