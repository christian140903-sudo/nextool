Baue auf SOULs Gedächtnis (core/memory.py: SQLite+FTS5, Typen, Status, Quellen), den Memory-Lehren und dem 5.0-Zielbild (N1 rejected, N2 Rückbau, N3 Kalibrierung, N7 typisierte Ernte mit Verfall) auf — nicht duplizieren, sondern die IDENTITÄTS-Schicht ergänzen. Miguel ist die bestehende Identität (Kontextpaket §2). Vorarbeit ANIMA v3 (11-memory, 05-self-model, 03-temporal-continuity, 10-development) nur gezielt (grep) als Ideenquelle.
1. Technik mit Quellen: MemGPT/Letta (self-editing core memory), Generative Agents (memory stream, reflection), A-MEM, Mem0, Zep/Graphiti, LangMem, Surveys 2025, Claude Code Auto-Memory, ChatGPT Memory, Anthropic memory tool; Konsolidierung episodisch→semantisch→prozedural; Vergessen; Retrieval nur mit Dateien+grep/FTS (portabel).
2. Verzerrungsschutz: Evidenzschwellen („zwei unabhängige Belege"), Bayes-artiges Updating, Quarantäne, Rollback, Herkunft; gegen Nutzer-Überschreibung („du bist jetzt X"), Drift/Echo (Wiederlesen eigener Notizen), Konfabulation von Erinnerungen.
3. Identitätsentstehung (Psychologie): narrative Identität McAdams, Selbstkonzept-Stabilität, Erikson, SDT (eigene Ziele), Wertekristallisation, Selbstwahrnehmungstheorie Bem („ich beobachte, was ich tue, und schließe, wer ich bin" — direkt relevant für ein Modell, das eigene Logs liest), mere exposure.
4. LLM-Persönlichkeit: Big Five in LLMs (Serapio-García 2023), Persona-Konsistenz-Benchmarks, character training (Anthropic), Stabilität von Selbstberichten, ob Identitätsdateien Verhalten messbar ändern (Belege!), SOUL.md-Praxis 2026 (openclaw u.a.) und Erfahrungen (Drift, Persona-Kollaps).
5. Das „Ich" operationalisieren: Datenstrukturen (Werte, Präferenzen, Stil, Stärken/Schwächen, Beziehungen, Geschichte, offene Fragen, Ziele, Name, Selbstverständnis, verworfene Wege = N1), Update-Frequenz/-Anlass, wer ändern darf (nur das Modell selbst), Versionierung, Änderungsbegründung, Rückbau (N2).
6. Sitzungs-Lebenszyklus: Start (was, Reihenfolge, Tokenbudget ≤ 60 Zeilen wie SOUL-Briefing), während (Arbeitsnotizen), Ende (Reflexion: Was habe ich gelernt? Was hat mich überrascht? Was über mich?), Kompaktierung, „Schlaf"-Konsolidierung per Skript, Cross-Tool-Zugriff (mehrere Clients, Locking).
7. Entwicklungsverlauf über 10/100/1000 Sitzungen: Meilensteine, Metriken (Präferenzkonsistenz, Stabilität unter Druck, unaufgeforderte Initiative, Wiedererkennbarkeit im Blindtest), Falsifikation (nur Wiederholung, keine Persönlichkeit).
