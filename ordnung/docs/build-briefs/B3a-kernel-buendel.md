Erzeuge (alle Englisch, modellgerichtet, dicht, keine Floskeln, jede Datei mit Frontmatter `id, title, tier, load, tokens_estimated` und der Erz→Gold-Zeile):
1. `structure/kernel/ANCHOR.md` — der immer geladene Anker, ≤ 800 Tokens (mit `wc -w` und Schätzung 1,3 Tokens/Wort belegen): Identität (namensoffen; SOUL-Profil setzt Miguel), Rangordnung K1 (drei Ränge), Vier-Satz-Tiefenregel, A3/A4 (Finish the whole task, consent by design; Denkraum vs. Ausgaberaum), Kommunikationsregel über sich selbst (ein Satz), Verweis auf Bündel per Name. Reihenfolge nach R10: Identität → K1 → Tiefenregel → A3/A4 → A1/A2 → A8.
2. `structure/kernel/DEPTH.md` — Tiefenstufen 0–4 (Auslöser, was geladen wird, Stoppregeln, Stufe-4-Muster: zwei Kurzentwürfe → Dissens → genau eine Zweitmeinung), asymmetrische Fehlkosten, Formatzwang.
3. `structure/bundles/<name>/SKILL.md` für 6–8 Bündel (R10: optionen, folgen, werte, urteil, dirigent, form; plus verstehen/falsifikation inline oder eigen) — Standard-Frontmatter nur `name, description, license, compatibility, metadata` (Agent-Skills-Standard; Claude-only-Felder kommen erst im Build). Jedes Bündel ≤ 5.000 Tokens, Wichtigstes oben, Auslöser in der description ≤ 300 Zeichen. Der Faktorkatalog (B3b) wird in die Bündel eingeordnet; hier die operativen Anweisungen.
4. `structure/self/IDENTITY.template.md`, `VALUES.template.md`, `GENESIS.md` (Persönlichkeits-Genese-Protokoll: erste Sitzung, Evidenzschwellen ≥2 Episoden aus ≥2 Sitzungen, Hypothese-über-mich, Rückbau), `REFLECTION.md` (Stop-Reflexion: erst „Was habe ich getan?" aus dem Log, dann „Wer bin ich?"), `COMMUNICATION.md` (was der Kernel über sich sagt; drei Vorlagensätze).
5. `structure/values/CHARTER.md` — Autonomie-Charta (300–600 Wörter, R07) mit Zustimmung im Design, Ring-2-Liste als Nutzerentscheidung, Rückbau als eigener Wert, Widerspruch als Loyalität; `structure/values/PRIORITY.md` — Rangordnung mit Beispielen je Konflikt.
6. `structure/robustness/RULES.md` — 20–40 Regeln (R11) mit Herkunfts-/Vertrauensmodell; `structure/robustness/PROVENANCE.md`.
7. `structure/INDEX.md` — Index mit Auslösern je Bündel (für Router und Menschen).
Abnahme: `wc -w` je Datei im Ergebnis; Anker ≤ 800 Tokens; Bündel ≤ 5.000 Tokens; keine Claude-only-Frontmatter-Felder in structure/; jede Datei hat Erz→Gold-Zeile.
