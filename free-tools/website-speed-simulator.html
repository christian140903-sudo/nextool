Frequently Asked Questions

How does the speed simulator work?
The simulator calculates estimated load times based on your resource configuration (images, scripts, CSS, fonts), connection speed, server response time, and optimization settings. It models real browser behavior including parallel downloads, render-blocking resources, and critical rendering path.
Is this as accurate as Google PageSpeed Insights?
This is a simulation tool, not a live page test. It estimates performance based on your inputs. For production sites, use it alongside Google PageSpeed Insights. The simulator is great for planning, comparing architectures, and understanding what affects load time before you build.
What is a good performance score?
90-100 is excellent (green), 50-89 is needs improvement (orange), and 0-49 is poor (red). These ranges align with Google's Core Web Vitals thresholds. Most well-optimized sites score 80+.
Can I share my simulation results?
Yes! Click "Share Results" to copy a URL that encodes your configuration. Anyone opening that link will see the same simulation setup and can run it themselves.
