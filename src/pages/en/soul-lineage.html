Soul Lineage: correctable memory for AI agents

Today, when a remembered fact turns out to be wrong, you can fix that one entry. What the assistant concluded or did because of it stays in place and keeps being used. Soul Lineage would record what was derived from what, so that a correction shows exactly what needs a second look.

Status

This page describes a plan. Nothing here is built or released; it becomes real only once it is in the repository and on npm. Planned for March to September 2027.

The problem

Monday a fact is remembered (“the customer runs an older database version”). Tuesday a conclusion is drawn from it (“feature X will not work, migrate”). Wednesday an action follows (a migration script and a pull request). Thursday the fact is corrected. Today only the fact changes; the conclusion and the action stay unmarked and nobody knows they rest on an error. With lineage, both would be flagged for review.

The idea is old: truth maintenance systems (Doyle 1979, de Kleer 1986) withdraw conclusions when an assumption is retracted. What is new is the setting: a language model does not reliably say which facts in its context it actually used. What was delivered into the context is knowable; what was really used is not.

What would be built

  1. Capture: when something is stored or run in a context, record which memories were delivered into it; clients can also declare the premises they used.
  2. Revoke with bounded doubt: revoking a memory starts with a dry run that shows the affected set; reachable conclusions and actions are marked doubtful within policy limits and go to a review queue. A person decides; nothing is deleted automatically.
  3. Share: the edge schema and propagation rules published as a specification separate from the code.

What this will not claim

  • Retrieved is not the same as used. Edges from delivery over-mark: they err on the safe side.
  • Doubt can spread too far; that is why every revocation starts as a dry run with limits.
  • No quality claim before a measurement exists — including if the result is negative.
